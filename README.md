# GPAway

GPAway 是一个可离线使用的个人学业管理网页，用来整理中美课程、记录成绩，并查看学分和绩点进度。内置金融学（国际金融方向）四年计划和辅修课程参考。

## 开始使用

1. 打开 [GPAway.html](GPAway.html)，点击 GitHub 文件页上的 **Download raw file**。
2. 在浏览器中打开下载的 HTML。打开后即可离线使用。
3. 在「设置」里选当前学期，再从「课程」录入或管理课程。

## 功能

- **学业概览** · 分别查看美方和中方的累计绩点、已获学分和学分完成率。
- **课程管理** · 按年级和学期查看计划，按课程名称或编号搜索，管理注册课程和辅修要求。
- **成绩与绩点** · 输入分数或等第，按设置中的规则计算绩点。
- **数据备份** · 在「设置」中导出或导入备份。换电脑、浏览器或移动 HTML 前，请先导出备份。

## 数据保存

公开版从空白学业记录开始。你录入的成绩和进度保存在当前浏览器，GPAway 不会把这些记录上传到 GitHub。GitHub 文件页用于下载，实际操作请在本地打开网页。
